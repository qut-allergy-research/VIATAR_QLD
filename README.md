Overview

This repository contains analysis code supporting the Queensland component of the VIATAR project.

The study uses real-world serum-specific immunoglobulin E (sIgE) data collected through pathology laboratories to investigate demographic and geospatial variation in aeroallergen sensitisation across Queensland, Australia.

Analyses examine variation in aeroallergen sensitisation according to age, sex, urbanicity, coastal proximity, and geographic location, with the aim of informing geographically relevant allergy testing, diagnosis, and management strategies.

Study design

Retrospective cross-sectional analysis of de-identified diagnostic sIgE data from individuals aged ≥12 years in Queensland, Australia, collected between 2019 and 2025.

Aeroallergen sensitisation was defined as sIgE ≥0.35 kU/L.
